# The International 2026 (TI15) — Swiss Stage Pick'Em

**Формат:** 16 команд, Swiss, усі Bo3. Топ-3 виходять напряму (1× 4-0, 2× 4-1).
Місця 4-13 грають Elimination Round: 5 проходять, 5 вилітають. Далі 2× 1-4 та 1× 0-4.
**Джерела (16):** 8 ІІ-моделей + 7 про-гравців/аналітиків (Ghostik, Topson, Arteezy, NS, Fishman, Sikle, Nix) + 1 Monte-Carlo симуляція (`Sim`). Правило: одна сутність — один голос.

Позначення: `4-0` / `4-1` = прямий вихід · `ADV` = проходить Elimination Round · `LOSE` = програє Elimination Round · `1-4` / `0-4` = виліт.

## AI vs Pro vs Sim — ключові розколи

- **Iron Wing:** про 4/7 → advance (Ghostik, Arteezy, NS, Fishman), 3/7 → lose; моделі + Sim → lose. Консенсус LOSE (9/16).
- **Aurora Gaming:** про 4/7 → lose (Ghostik, Topson, NS, Nix), але моделі + Sim → advance. Головний кандидат на хедж.
- **Sim vs консенсус:** симуляція збігається з консенсусом усюди, крім двох місць — ставить **OG → 1-4** і **Team Resilience → lose** (у консенсусі навпаки). Це підтверджує, що ці два дна найменш визначені.

## Симуляція (Sim)

`ti15_swiss_sim.py` — Monte-Carlo (300k прогонів) по офіційних правилах Swiss-стадії TI15
(2 групи по 8, R2-R3 усередині групи, R4 крос-груповий, R5 макс. розрив сідів, Elimination Round
із вибором суперника). Рахує ймовірності кожного результату для кожної команди та підбирає
EV-оптимальний pick'em під максимум очок. Очікувано вгадується **~5.86 / 16** слотів (така вже дисперсія Swiss).

```bash
python ti15_swiss_sim.py
```

Стовпець `Sim` у таблиці = EV-оптимальний бракет цього скрипта (рахується як один голос).
