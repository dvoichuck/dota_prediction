# The International 2026 (TI15) — Swiss Stage Pick'Em

**Формат:** 16 команд, Swiss, усі Bo3. Топ-3 виходять напряму (1× 4-0, 2× 4-1).
Місця 4-13 грають Elimination Round: 5 проходять, 5 вилітають. Далі 2× 1-4 та 1× 0-4.
**Джерела:** 8 ІІ-моделей (незалежний аналіз) + 7 про-гравців/аналітиків (Ghostik, Topson, Arteezy, NS, Fishman, Sikle, Nix). Правило: одна сутність — один голос.

Позначення: `4-0` / `4-1` = прямий вихід · `ADV` = проходить Elimination Round · `LOSE` = програє Elimination Round · `1-4` / `0-4` = виліт.

## Симуляція (Monte-Carlo / EV) — окремо від консенсусу

Не входить у голосування таблиці вище. Це не ще один «пік», а **калібрування**: Elo → ймовірності слотів → призначення команд під фіксовані квоти формату так, щоб максимізувати очікувану кількість правильних слотів у pick'em.

**Що це означає**
- Кожна серія — Bo3 з імовірністю з Elo (`ti15_swiss_sim.py`, divisor 600).
- 300k прогонів Swiss за правилами TI15 (групи, R2–R5, Elimination Round з раціональним вибором суперника).
- Для кожної команди виходить розподіл по слотах (`4-0` … `0-4`), не один вердикт.
- **EV-optimal pick'em** — спільне призначення: рівно 1× 4-0, 2× 4-1, 5× ADV, 5× LOSE, 2× 1-4, 1× 0-4. Слот команди може відрізнятися від її mode-результату (наприклад Vision: ElimW/4-1 трохи частіші за 4-0, але EV ставить 4-0 через квоту).
